# Repository instructions

For every UI, layout, navigation, responsive, or component change:

1. Use `.agents/skills/yoyoworks-ui/SKILL.md`.
2. Follow `design-system/MASTER.md`.
3. Apply any matching file in `design-system/pages/`.
4. Keep concrete design values in `assets/theme.css`; do not duplicate them in
   documentation or page-specific styles.
